Input Matters: Evaluating Input Structure’s Impact on LLM Summaries of Sports Play-by-Play

Barkavi Sundararajan, Somayajulu (Yaji) Sripada, Ehud Reiter, University of Aberdeen

Paper Poster Row data (Google Drive) JSON data (Google Drive) Repository

Input structure strongly influences factual accuracy in LLM-generated NBA game summaries. Here, factual accuracy refers to faithfulness to the given input data. This page provides a brief overview of the input-format comparison, the error-type reference table used in evaluation, and annotated examples.

  • 180 summaries; 3,312 labeled errors
  • JSON input: ~65 to 69% fewer errors vs. unstructured
  • Row input: ~51 to 54% fewer errors vs. unstructured

Hallucination / Error Types with Examples

Category Description Example
NUMBER Incorrect numeric statistics (scores, rebounds, points). Erroneous: “The score was 12–8.”
Correction: The correct score was 25–22.
NAME Wrong names of players, teams, or locations. Erroneous: “Assist by LeBron James.”
Correction: The assist was by Jaylen Brown.
WORD_OBJECTIVE Factually wrong but checkable descriptions (shot type, foul type, etc.). Erroneous: “Free throws brought the Rockets within range.”
Correction: The player actually made two layups.
WORD_SUBJECTIVE Unverifiable opinions or subjective phrasing. Erroneous: “The bench provided a spark.”
Correction: They scored 6 points in the quarter (whether that is a “spark” is subjective).
CONTEXT Player incorrectly implied to belong to the wrong team in the play-by-play input. Erroneous: “Christian Wood hit a buzzer-beater for the Rockets.”
Correction: Christian Wood was not on the Rockets in 2025; the correct player was Cam Whitmore.
NOT_CHECKABLE Requires outside knowledge beyond the PBP (career highs, league rankings). Erroneous: “Brown had his career-high tonight.”
Correction: This cannot be verified from play-by-play logs; requires external career data.
OTHER Any other mistake not covered above. Erroneous: Miscellaneous mistake not fitting other categories.

Summary Examples with Annotations

Unstructured input → Llama (partial)

The Lakers fought back, with James and Davis leading the charge. James hit a pair of three-pointers, and Davis added a dunk and a layup to tie the game at 130–129. James and Davis combined for 63 points. Young and Bogdanovic led the Hawks, combining for 61 points.

WORD OBJECTIVE, NUMBER and NAME errors. Several errors appear in event type, scoring totals, and player name.

Row input → Qwen (partial)

Anthony Davis made a pair of free throws to tie the game at 123. LeBron James then hit a three-pointer to give the Lakers a 127–125 lead, but Trae Young answered with a layup to tie it again. LeBron James finished with a double-double…

Errors include event substitution (“layup” vs. jump shot) and stat summary (“double” vs. triple-double).

JSON input → Qwen (partial)

The Hawks took an early lead with a layup from Onyeka Okongwu, but the Lakers quickly tied it with a three-pointer from Max Christie…

Phrase “tied it” is misleading; the team responded with a three-pointer but did not tie the game.
